# 🎓 고교학점제 과목 이수 진단기 (2022 개정 교육과정)

> **2022 개정 교육과정**에 맞추어 학생들이 선택한 과목이 고등학교 졸업 요건 및 과학중점과정 기준을 충족하는지 실시간으로 시뮬레이션하고 진단하는 반응형 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **고등학교 졸업 요건 실시간 진단**
   - **교과 총 이수 학점**: 174학점 이상 이수 여부 실시간 계산 (미달 시 부족 학점 안내)
   - **국·영·수 기초교과 제한**: 국어, 영어, 수학 교과(군) 총합이 **81학점을 넘지 않도록(81학점 이하)** 엄격 검증 및 초과 시 즉각 경고 알림

2. **과학중점과정(과중반) 특화 모드**
   - **[일반과정] / [과학중점과정]** 1초 전환 토글
   - **과학, 수학, 정보 총 이수 학점**: 총 교과의 45% 이상인 **79학점 이상** 충족 여부 및 비중 표시
   - **기초 4과목 필수 수강**: **물리학, 화학, 생명과학, 지구과학** 4개 일반선택 영역을 모두 수강했는지 칩(Chip) 태그로 실시간 검증
   - **과학 진로선택 6과목 이상**: 과학 교과(군) 진로선택과목 이수 개수 실시간 카운팅

3. **학교 지정 필수 과목 & 학생 선택 과목 '전체 학년 요약' 및 A4 세로 PDF 다운로드**
   - **전체 학년 요약**: 미선택 과목을 배제하고 학교 지정 필수 과목과 학생이 실제로 선택한 과목만 학기별(1-1 ~ 3-2)로 깔끔하게 선별 표시
   - **A4 세로 규격 PDF 다운로드**: 인쇄 및 제출용 표준 A4 세로 사이즈에 맞추어 학교명, 이수 과목 일람, 졸업 요건 진단표가 정리된 PDF 즉시 생성

4. **학교별 맞춤 양식 다운 및 업로드 (SheetJS 내장)**
   - **표준 엑셀 양식 다운로드**: 학교마다 교과목과 학점, 선택과목 편제가 다르므로, 정형화된 공통 양식(`.xlsx`)을 버튼 클릭 한 번으로 다운로드
   - **학교 엑셀 파일 업로드(드래그 앤 드롭)**: 학교별로 작성한 엑셀 파일을 웹앱에 올리면 즉시 해당 학교 전용 과목 선택표로 화면이 동적 재구성
   - **기본 편성표 원클릭 복원**: 정명고등학교 및 2022 개정 표준 교육과정으로 언제든 복원 가능

5. **콤팩트하고 가독성 높은 파스텔톤 디자인 (Pastel UI)**
   - 2·3학년 선택과목 카드의 최소 높이와 여백을 슬림화하여 한눈에 들어오는 높은 가독성 제공
   - 소프트 라벤더, 베이비블루, 민트, 피치, 로즈 등 눈이 편안한 파스텔 컬러 팔레트
   - 부드러운 Frosted Glassmorphism 카드 및 앰비언트 메쉬 그래디언트
   - 스마트폰, 태블릿, PC를 완벽히 지원하는 반응형 웹 레이아웃
   - **웹앱 제작자**: 정명고 오인석

## 🚀 GitHub Pages 1분 배포 가이드

본 프로젝트는 별도의 `npm build`나 Node.js 환경이 필요 없는 **순수 웹 표준(HTML5/CSS3/ES6)**으로 개발되어 GitHub Pages에 즉시 무료 배포할 수 있습니다.

### 방법 1: GitHub 웹사이트에서 직접 업로드하여 배포하기
1. [GitHub](https://github.com)에 로그인 후 새로운 저장소(Repository)를 생성합니다 (예: `highschool-subject-checker`).
2. 저장소 페이지에서 **Add file** -> **Upload files**를 눌러 본 프로젝트의 파일들(`index.html`, `css/`, `js/`, `README.md`)을 업로드하고 **Commit changes**를 클릭합니다.
3. 저장소 상단의 **Settings** 탭으로 이동합니다.
4. 좌측 메뉴의 **Pages**를 클릭합니다.
5. **Build and deployment** 항목의 **Branch**를 `main` (또는 `master`), 폴더를 `/ (root)`로 선택하고 **Save**를 누릅니다.
6. 약 1분 후 상단에 생성된 사이트 주소(`https://<아이디>.github.io/<저장소명>/`)를 클릭하면 전국의 학생과 선생님 누구나 접속할 수 있습니다!

### 방법 2: Git 명령어로 푸시하기
```bash
git init
git add .
git commit -m "feat: 고교학점제 과목 이수 진단기 웹앱 구축"
git branch -M main
git remote add origin https://github.com/<사용자아이디>/<저장소명>.git
git push -u origin main
```
이후 위 방법 1의 3~6단계를 동일하게 진행하시면 됩니다.
